## Working notes (track seed)

Connaughton, Colm; Jeroen; and Paillusson, Fabien. 2026. "What is ergodicity?"
Working notes dated 28/09/2026 for the introduction to a *Philosophical
Transactions of the Royal Society A* theme issue on ergodicity.
Repository: <https://github.com/colm-connaughton/ergodicity-intro>
(branch `PTRSA-final-edits`, file `ergodicity.pdf`).

The notes' running header names the authors as "Colm, Jeroen and Fabien." The
repository owner and commit history identify Colm Connaughton; Fabien Paillusson
appears as coauthor of Underwood & Paillusson in the same volume. The notes and
repository README do not state Jeroen's surname; this track therefore cites the
second author by given name only.
